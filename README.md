# InovaGestão — Simplifique a Gestão do Seu Negócio

Landing page institucional para a InovaGestão, focada na oferta de soluções de automação de processos, criação de dashboards inteligentes e rotinas de backups automáticos para pequenas empresas e MEIs.

## Visão Geral

- **Propósito:** Apresentar os pilares de serviços de gestão e automação para micro e pequenas empresas, destacando ganhos de eficiência, tomada de decisão baseada em dados e segurança de informações.
- **Status:** Entregue / Portfólio.

## Stack Tecnológica

- **HTML5:** Estrutura semântica dividida em seções (Hero, Sobre, Serviços, Contato).
- **CSS3 (`styles.css`):** Layout responsivo baseado em Flexbox/Grid, tipografia limpa e estilização de cards de serviços.
- **JavaScript (`scripts.js`):** Script base para interações na interface.
- **Dependências:** Nenhuma (zero build / zero runtime dependency).

## Como Executar

No host local (Windows), via Git Bash ou PowerShell:

```bash
# Opção 1: Abrir diretamente no navegador padrão
start index.html

# Opção 2: Servir via servidor HTTP local
python -m http.server 8080
# Acessar: http://localhost:8080
```
